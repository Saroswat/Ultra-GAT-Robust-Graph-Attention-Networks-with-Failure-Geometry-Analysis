# Results and claims

## Reproducible benchmark protocol

The public benchmark compares GCN, GAT, and GATv2 on identical Planetoid splits. Each result should
report five seeds, validation-based early stopping, test accuracy, expected calibration error, model
size, and robustness area under the curve for edge and feature corruption.

Run it with:

```bash
uv run ultragat benchmark --models gcn,gat,gatv2 --seeds 11,22,33,44,55
```

The generated `artifacts/benchmark/benchmark.json` is the machine-readable source of truth. The
verified run is versioned at [`results/citeseer-five-seed.json`](../results/citeseer-five-seed.json).

## Verified CiteSeer benchmark

Executed on 30 August 2026 with seeds 11, 22, 33, 44, and 55 using the checked-in configuration.

| Model | Test accuracy | ECE ↓ | Edge AUC ↑ | Feature AUC ↑ |
| --- | ---: | ---: | ---: | ---: |
| GCN | **67.74% ± 0.60%** | 0.0727 ± 0.0055 | **0.6681 ± 0.0076** | **0.6682 ± 0.0060** |
| GAT | 67.62% ± 1.31% | **0.0348 ± 0.0110** | 0.6668 ± 0.0129 | 0.6607 ± 0.0084 |
| GATv2 | 67.24% ± 1.19% | 0.0419 ± 0.0179 | 0.6626 ± 0.0129 | 0.6556 ± 0.0206 |

The clean-accuracy differences are small relative to run-to-run variation. GAT has the strongest
calibration in this protocol; GATv2 does not outperform the simpler baselines on clean accuracy. GCN
retains the strongest average accuracy under both deterministic corruption sweeps. The
stress-test table is generated by the benchmark command alongside these metrics.

## Exploratory notebook observations

The original notebook contains many iterative experiments on CiteSeer. Its strongest later runs
reported roughly 70% raw test accuracy and 73% after label propagation. Those runs also showed
near-perfect validation accuracy, so they are hypotheses to reproduce, not headline benchmark claims.
An attempted student self-training stage fell from about 61% to 42%, which is retained as a useful
negative result. The package benchmark exists specifically to remove favorable-run selection and make
the comparison auditable.
